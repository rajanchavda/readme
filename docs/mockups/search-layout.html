Where should the search results live?

Both show matches with the words around them. The dim number at the bottom corner of each page is the page-number idea, shown here so you can judge it too.

A

Sidebar, like Contents and Highlights

⌘F slides in a panel over the left of the book. The list stays open while you click through matches, and the page behind it changes as you go. Esc or ⌘F closes it.

B

Floating box, gone once you pick

⌘F opens a small box over the book, like Spotlight. Arrow keys move through matches and Return goes there and closes the box. To try a different match, press ⌘F again and the last search is still there.
