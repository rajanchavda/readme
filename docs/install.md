# Installing Readme

Readme needs a Mac with Apple silicon (M1 or later) and macOS 14 Sonoma or later.

## 1. Copy it to your Applications folder

1. Double-click **Readme.dmg** to open it.
2. In the window that opens, drag the **Readme** icon onto the **Applications** folder.
3. Close the window. In the Finder sidebar, click the eject button next to **Readme**.

## 2. Open it the first time

Readme isn't yet registered with Apple, so the first time you open it your Mac asks you to confirm that you trust it.

1. Open your **Applications** folder and double-click **Readme**.
2. A message appears. On macOS 15 and later it says **"Readme" Not Opened** and that Apple could not verify it is free of malware. On macOS 14 it says **"Readme" can't be opened because Apple cannot check it for malicious software**. Click **Done** (or **OK**). Don't click **Move to Trash**.
3. Open the **Apple menu** > **System Settings**, then click **Privacy & Security** in the sidebar.
4. Scroll down to **Security**. You'll see a line saying **"Readme" was blocked** to protect your Mac (on macOS 14: **"Readme" was blocked from use because it is not from an identified developer**). Click **Open Anyway** beside it.
5. Your Mac asks once more. Click **Open Anyway** (on macOS 14: **Open**). Then enter your Mac's password or use Touch ID.

Readme opens. **You only have to do this once.** From now on it opens like any other app, from your Applications folder or the Dock.

**If there's no Open Anyway button:** on macOS 15 and later it only shows for about an hour after you tried to open Readme. Double-click Readme in Applications again, click **Done**, then go back to **Privacy & Security**.

**A quicker way on macOS 14:** in your Applications folder, right-click (or Control-click) **Readme**, choose **Open**, then click **Open** in the message that appears. Newer versions of macOS don't offer this, so use the steps above there.

## Your first book

Drag an EPUB file onto the shelf, then click it to start reading. You can also drop an EPUB on Readme's icon in the Dock.
